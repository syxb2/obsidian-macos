# 更新记录

## 1.2.0 — 2026-09-22

打开 Show ribbon 时的左边栏与功能区修好了，开关边栏的动画也与原生对齐。

- 打开 Show ribbon 后，左边栏不再是原来那套悬浮样式的残留：左边缘到窗口不再留 8px 的
  缝，文件浏览器也不再被挤窄一整栏（44px），功能区图标回到这一栏的居中位置
- 功能区（ribbon）铺满整个窗口高度，窗口左上角（红绿灯所在处）不再露出工作区的底色
- 功能区的底色跟着「旁边是谁」走：左边栏开着时与边栏同色，左边栏收起时与编辑器连成一片；
  半透明窗口、窗口失焦也各有对应取值
- 窗口失焦 / 聚焦切换时，功能区的底色与边栏同时切换，不再一前一后
- 去掉 Baseline 自带的缩放进场动画：开关边栏时，边栏里的内容不再从 95% 放大到 100%
- 左边栏的内容改为从左侧滑入，与右边栏的右侧滑入互为镜像（原来左边栏的内容是原地露出）
- 弹窗（设置窗口也在内）打开时不再缩放，去掉 Baseline 给 `.modal` 写的入场动画，直接出现
- 顶部选项卡与 Obsidian 自己的按钮统一改为两端全圆的胶囊形：边栏 / 编辑器的选项卡、
  功能区和视图右上角那排图标按钮、文件浏览器的操作行、设置与弹窗里的按钮都在内；
  插件面板（如 Claudian）、笔记正文、输入框与下拉框保持原样
- `docs/customization.md` 随代码更新

## 1.1.1 — 2026-09-21

边栏底色调整：暗色下比编辑器浅一点点。

- 暗色下的左右边栏、设置窗口左侧那一列改用 `--background-primary-alt`，也就是编辑器
  混 3% 白（`#252525` 对 `#1e1e1e`）。Baseline 原来那条是 `calc(l - 2)`，边栏比编辑器深
- 亮色的边栏底色不变，仍是 `--background-secondary`（编辑器混 5% 黑，`#f2f2f2`）
- 新增 `docs/README.md` 的目录说明与 `AGENTS.md` 的仓库约定，`docs/customization.md`
  里边栏底色那一节随代码一起更新

## 1.1.0 — 2026-09-21

改成「从 Baseline 源码改」的项目，主题外观与 1.0.1 一致（只少了设置面板相关的样式）。

- `src/` 现在就是 Baseline 的 SCSS 源码：同名目录、同名文件，改动写在对应位置，
  不再是把编译好的 CSS 拿来打补丁
- 未启用的配色、布局、元素风格、设置面板等文件从源码里删除；挂在未启用开关上的
  条件与规则一并消除，`theme.css` 只保留这一种样式
- 固化的 13 个 CSS 变量写在 `src/app/config.scss`
- `theme.css` 由 dart-sass 编译（`npm install && npm run build`），产物已提交
- 从 Baseline 3.2.12 派生一次；仓库里不放上游副本，派生基线（版本、commit、md5）
  记在 `docs/` 里
- 工作流增加「从源码重新编译后 theme.css 是否有变化」的校验

## 1.0.1 — 2026-09-21

项目结构调整，主题本身没有任何视觉变化。

- Baseline 3.2.12 的整个仓库内置到 `upstream/baseline/`（1.1.0 起不再内置），构建不再需要联网或
  另外下载 Baseline；主题的改动也全部内化进根目录的 `theme.css`
- `theme.css` 从「脚本生成的压缩产物」变成项目自己的样式源文件，改成可读格式
  （一个选择器一行、一条声明一行），直接编辑它即可
- 构建脚本从 `src/` 挪进 `tools/`，定位改为「换基线版本时才用的重建工具」
  （1.1.0 起统一为 `tools/derive-src.py`）
- 工作流增加「内置的 Baseline 是不是 3.2.12 原样副本」的校验

## 1.0.0 — 2026-09-21

首个版本，基于 Baseline 3.2.12。

- 固化一套 Baseline Style Settings 配置，主题不再提供任何可调项
- 左侧栏由悬浮卡片改为与右侧栏一致的贴边面板（去掉外边距、圆角、阴影、
  为浮卡做的内边距补偿）
- 去掉左右边栏与编辑器之间的分隔线
- 关闭 Translucent window 时，左右边栏使用浅灰底色，而不是继承白色工作区
- 设置窗口的左侧栏改为贴边、同色的普通面板
- 移动端与平板保持 Baseline 原样
- 仓库按 Baseline 的目录结构整理：`src/` 集中放构建输入，
  原先作为可选片段（`snippets/`）给出的调整已全部固化进 `theme.css`，
  主题不再区分「本体」与「可选增强」
