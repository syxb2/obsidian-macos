# 截图放这里

仓库里唯一没法自己生成的就是截图。文件名按下面的约定放，README 里已经留好了引用位置。

| 文件 | 内容 |
| --- | --- |
| `img/hero.png` | README 顶部大图：整个 Obsidian 窗口，亮色，左右边栏都展开 |
| `img/preview-light.png` | 亮色下的工作区 |
| `img/preview-dark.png` | 暗色下的工作区 |
| `img/preview-settings.png` | 设置窗口，能看到贴边的侧栏 |
| `obsidian-macos.png`（仓库根目录） | 主题缩略图，和 Baseline 的 `baseline.png` 位置对应 |

README 顶部现在是注释状态，`hero.png` 放好之后把 `README.md` 里的
`<!-- ![](img/hero.png) -->` 去掉注释即可。

几点建议：

- `Cmd` + `Shift` + `4` 再按空格可以连带阴影截整个窗口，比全屏截图更适合放进 README。
- 编辑器里最好有真实内容（字体和排版也是主题的一部分），但提交前确认画面里没有隐私内容。
- 宽度 1400–1600px 足够，GitHub 会自己缩放。
- 缩略图建议 1600×1000 左右，主题商店里就是这个比例。
- 截图前关掉悬浮在其他应用之上的窗口（例如各类 AI 助手面板），否则会一起被截进去。
